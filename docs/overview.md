# Overview

This repository holds the MoVoC project: morphology-aware subword vocabulary
construction for Ge'ez-script languages (Amharic, Tigrinya, Tigre, Ge'ez),
published as *MoVoC: Morphology-Aware Subword Construction for Ge'ez Script
Languages*, Findings of EMNLP 2025 (arXiv:2509.08812).

It contains two distinct bodies of work, kept strictly apart:

| | What it is | Where |
|---|---|---|
| **Original** | Artifacts and values belonging to the published paper | `original/`, `original/published_results/` |
| **Reconstruction v2** | Independent re-implementation, reproduction and audit | `reconstruction_v2/` |

## The distinction that matters

Published values are **cited, never recomputed or overwritten**. Reconstruction
values are **new measurements**, generated by this repository's own pipeline
against the released artifacts.

Where the two disagree, the disagreement is documented — not reconciled by
adjusting either side. No reproduction result in this repository was tuned toward
a published number.
