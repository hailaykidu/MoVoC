# Version 2 reconstruction results

Every file in this directory was **generated by the current repository**:
reimplemented code, newly built vocabularies, newly trained checkpoints, and
a reconstructed evaluation pipeline.

These are **new measurements**. They are not the paper's reported values,
not corrections to them, and not verifications of them.

## Contents

```
reconstruction_v2/
├── intrinsic/
│   ├── paper_tables_reconstruction_v2.json        Tables 2 & 4 layout, held-out split
│   ├── paper_tables_leaky_reconstruction_v2.json  in-sample variant, for contrast
│   ├── intrinsic_eval_reconstruction_v2.json      per-language intrinsic metrics
│   └── extended_arms_build_reconstruction_v2.json extended verification arms
└── mt/
    ├── table3_reconstruction_v2.json              multi-seed MT aggregate
    └── README.md                                  MT run details and findings
```

All files are byte-identical copies of the working artifacts; see
[`../README.md`](../README.md) for the source-path mapping.

## Status of these results

**Intrinsic (Tables 2 and 4).** Produced by `evaluation/intrinsic/paper_tables.py`
from the reconstructed implementation and the released annotations. The
default run scores a held-out half of each annotation set; the `_leaky`
variant reproduces in-sample scoring for contrast. Both files carry a
`not_a_reproduction` field stating that the values are computed fresh and
are not comparable to the paper's.

**Extrinsic / MT (Table 3 layout).** Produced by `scripts/score_multiseed.py`
from 18 newly trained checkpoints. The pipeline reconstruction succeeded,
but the models did not reach a converged translation regime, so **these
results support no tokenizer comparison in either direction** — see
[`mt/README.md`](mt/README.md) and
[`../../docs/MT_Reconstruction_Audit.md`](../../docs/MT_Reconstruction_Audit.md).

## Why these must not be merged with the published values

Summarised in [`../../docs/reconstruction_vs_original.md`](../../docs/reconstruction_vs_original.md).
In short: the pipeline that produced the published figures is unavailable,
so no run performed now can be shown to follow the same procedure; the scale
of the published BLEU column is unresolved; and the MT reconstruction did
not reach a converged regime. Placing the two side by side in one table
would imply a comparability that does not exist.
